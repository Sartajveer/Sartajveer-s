SOLAR SYSTEM VR - install on Vive Focus Plus
1. Upload this whole folder to any HTTPS host (Netlify Drop: app.netlify.com/drop, GitHub Pages, Cloudflare Pages). VR needs https://
2. On the headset, open that address in the Wave browser. Wait for it to load once.
3. Bookmark it or add it to the browser home page. After the first load it works offline.
4. Tap "Enter VR". Trigger = select/fly, touchpad up/down = time speed, grip = home.
